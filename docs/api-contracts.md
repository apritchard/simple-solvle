# API Contracts

## Restriction String Format
`wordRestrictions` is the path segment that encodes the current puzzle knowledge. It is generated by the frontend in `generateRestrictionString` and parsed by `WordRestrictions`.

Each available letter appears once. A letter may be followed by:

- position digits, meaning the letter is known at those 1-based positions.
- `!`, meaning the letter is required but its exact position is unknown.
- `!` plus position digits, meaning the letter is required and excluded from those 1-based positions.
- `^N`, meaning the letter appears at least `N` times.

Examples:

- `a` means `a` is available.
- `c1` means `c` is required in position 1.
- `t!12` means `t` is required, but not in positions 1 or 2.
- `u3!4` means `u` is required in position 3 and not allowed in position 4.
- `e^2!45` means `e` appears at least twice, but not in positions 4 or 5.

Agents changing tile coloring, keyboard state, or solver filtering should keep frontend generation and backend parsing in sync.

## Shared Query Parameters
Most `/solvle` endpoints accept:

- `wordList`: dictionary selection, default `SIMPLE`.
- `wordConfig`: scoring/heuristic config, default `SIMPLE`.
- `hardMode`: restrict guesses to current known constraints, default `false`.
- `requireAnswer`: restrict suggestions to possible answers, default `false`.

## Endpoints
- `GET /solvle/{wordRestrictions}` returns `SolvleDTO`.
- `GET /solvle/score/{wordRestrictions}/{wordToScore}` returns `WordScoreDTO`.
- `GET /solvle/scoreTuple/{tupleString}` returns `TupleScore`.
- `GET /solvle/{wordRestrictions}/best/{bestNWords}` returns a set of `TupleScore`.
- `GET /solvle/submitTupleJob/{tupleString}` returns a `SolveJob`.
- `GET /solvle/{wordRestrictions}/playout` returns a set of `PlayOut`.
- `GET /solvle/solve/{solution}` returns an ordered list of guesses.
- `GET /solvle/rate/{solution}` returns `GameScoreDTO`.

## Response Shapes
`SolvleDTO`:

- `restrictionString`: echoed restriction string.
- `wordList`: viable solution suggestions as `WordFrequencyScore[]`.
- `fishingWords`: information-gain guesses as `WordFrequencyScore[]`.
- `bestWords`: partition/entropy suggestions as `WordFrequencyScore[]`, or `null` when not calculated.
- `totalWords`: count of viable words.
- `wordsWithCharacter`: character count map.
- `knownPositions`: common-position groupings as `KnownPositionDTO[]`.

`WordFrequencyScore`:

- `naturalOrdering`: stable sort/order value.
- `word`: suggested word.
- `freqScore`: frequency/fishing score.
- `partitionStats`: optional partition/entropy data.

`WordScoreDTO`:

- `remainingWords`: expected average remaining words.
- `fishingScore`: information-gain score.
- `entropy`: entropy score.

`KnownPositionDTO`:

- `position`: human-readable shared-position description.
- `words`: matching words for that position grouping.
- `recommendations`: suggested words for that grouping.

`GameScoreDTO`:

- `rows`: per-guess `GameScoreRow[]`.
- `skill`: average skill score.
- `luck`: average luck score.
- `heuristic`: average fishing/heuristic score.

`GameScoreRow`:

- `playerWord`, `playerScore`, `solvleWord`, `solvleScore`, `actualRemaining`, `skill`, `luck`, `heuristic`.
